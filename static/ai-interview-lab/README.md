# AI Interview Lab

한국어 AI 엔지니어링 면접 연습 사이트입니다. 질문은 ninetyhe-90의 [영어판](https://github.com/ninetyhe-90/ai-engineering-interview-questions-company-wise-zh-cn/blob/main/README.en.md)을 바탕으로 번역했으며, 원본은 [Outcome School의 질문 모음](https://github.com/pallavi-shekhar/ai-engineering-interview-questions-company-wise)입니다. 라이선스와 변경사항은 `LICENSE`와 `NOTICE`를 참고하세요.

문제은행의 주제 선택 목록은 각 주제의 전체 질문 수를 보여줍니다. 문제은행은 기본적으로 한 페이지에 100개를 보여주며 20, 50, 100, 200개 중 선택할 수 있습니다. 학습 기록은 브라우저에 저장됩니다. 이 폴더를 HTTP 서버로 제공해 로컬에서 확인할 수 있으며, 사이트 전체는 저장소의 Hugo 배포를 따릅니다.
